# ライブラリ仕様


## テーマ対応

基本的に上位のアプリのcssによる切り替えに対応できるようにする。
このライブラリ内のコンポーネントごとのテーマ変数定義は避ける。
現状、このライブラリ(restar-app)を使用する用途として、UIの統一もあるため。

```css
--text-color
--text-primary
--text-secondary

--bg-color
--bg-secondary
--bg-primary
```

上記のようにprimary, secondaryを使用するものとしますが、上位からの互換的に`color`も使用できるものとします。
